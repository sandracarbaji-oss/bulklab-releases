# BulkLab releases

Public distribution point for [BulkLab](https://github.com/sandracarbaji-oss/bulklab)
(source stays private there). This repo holds only what a customer already
gets once they install the app:

- `appcast.xml` — the Sparkle update feed
- Signed release installers (as GitHub Releases assets)
- Release notes

Nothing here is a substitute for the source repo, and nothing sensitive
(private keys, personal data, unrelated project files) should ever be
committed here.
